# 独立视觉展厅

Mode: Experience；侧栏工具属于 Operate。

代码原生 Three.js 场景是首屏主角。继承现有暖阳木质双层工作室，工具栏用纸色和森林绿，系统字体，右侧单列操作。移动端场景在前、操作在后。对照主题改为蓝色建筑、冷光与矿物白界面，保持同一地图与交互锚点。

访客路径：环绕总部 → 分别选择空间、界面和角色配色 → 导入本地 GLB 检查 → 试用登录、编辑器与员工面板 → 按贡献指南提 PR。无需真实公司登录，无后端依赖。保存演示稿仅保存在本次会话，真实业务写入给出明确拒绝。

范围是现有视觉系统的提取与独立验证，不是重新设计总部，也不替换老板肖像。需要保留布局、楼梯、门禁边界与宿主控制器。QUALITY BAR：真实共享代码、真实 WebGL、错误可恢复、390px 无横向溢出、明确演示边界、来源和构建可验证。
