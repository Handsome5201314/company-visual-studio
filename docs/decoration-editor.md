# 装修创作台与主游戏接入

创作台位于 `apps/editor/index.html`，不需要公司账户。设计在当前浏览器处理，可导出轻量设计 JSON、预览 PNG 和含真实资源的完整主题 ZIP；导出本身不会上传或修改正式游戏。Showroom 页头可进入创作台与装修市场。独立静态站不自带后端；部署到私有宿主后，市场连接宿主实际审核目录。

`src/decoration-editor.ts` 导出的 `createDecorationEditor(host, initial, options)` 与主游戏共用。`initial` 包含受验证的 `theme` 和 `scene`；`options.save/submit` 由私有宿主提供真实API，公共入口不提供后端写入。返回 `design` 快照和 `dispose()`；关闭面板必须dispose。`readOnly` 拒绝选中/拖动，允许镜头环绕；可提供 `comparison` 与 `comparisonAssetBase` 比较当前正式版本。

支持13类 `MODEL_IDS`，陈设编辑范围由 `decoration-safety.js` 限定在9个安全体积，包含原四区、老板台面、会客台面、休息区、楼上墙边和顶部区域。数值摆放和拖动共用校验，位置按0.05米吸附；重叠、超出体积及未知模型会报错。建筑拓扑、楼梯、碰撞、门禁与员工位置仍归宿主权威控制，不能导入任意新地图。

可以添加、删除、替换、旋转、缩放陈设，编辑8组建筑饰面的颜色/粗糙度/金属度，替换7个固定家具位的允许模型，调整最多4个装饰点光源。支持50步撤销/重做及小于1MiB的设计JSON。只读、比较中和提交中的控制会锁定。手机工具位于场景之后，精确操作有表单入口。

轻量设计JSON仍不是完整包。展开“完整主题包”，填写作者、ID、版本、仓库和源码基线提交，导出 ZIP。导出器读取13类实际模型，保留自定义模型映射，生成真实3D封面、清单、逐文件SHA256/字节数、MIT/CC0许可和说明。源码基线指生成器代码提交，不是包含清单本身的自引用提交。

完整 ZIP 可交给宿主“公司装修→导入完整主题包”进入本人私有草稿，之后提交老板审核；不会进入公开市场。公开投稿则到“装修市场→我的投稿”，确认公开及再分发权，上传后再提交总部。GitHub 贡献者解包至 `themes/<包ID>/` 后提交 PR；其安全检查仅产生只读预览，不会自动认证或上架。正式应用和历史回滚仅由老板执行。首版ZIP支持本编辑器输出的stored格式；通用deflate ZIP需另行支持。

`OfficeVisuals.setDecoration(scene)` 仅生成可编辑视觉层；`OfficeVisuals` 支持已验证的 `packageAssetBase`，只有明确登记的静态模型走包内路径，Draco解码器仍来自宿主可信资源。加载候选主题时应在游离Scene中构建，全部资源及陈设成功才替换旧Root，失败dispose候选并保留旧视觉。角色和多人Root不放入装修Root。

未来科技变体含模块地板、导光楼梯、悬架工位、环灯与外部塔群，沿用同一布局契约。不能把新建筑布局直接当主题应用，新的布局须另行迁移私有碰撞与门禁。
