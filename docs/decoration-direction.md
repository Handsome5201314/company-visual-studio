# 装修市场与创作台：方向与验收标准

这是既有视觉系统扩展。PRODUCT.md / DESIGN.md 保持原有权威，不重做全站品牌。用户确定暖阳、木质、两层挑空的动画工作室，现有 `hq-fixed-layout-v1` 不变。市场与编辑器属于 Operate；Showroom 继续以 Three 场景为主的 Experience。代码原生实现，无批准的图片设计稿。

## First viewport

Showroom 以完整可环绕总部证明共享视觉，页头进入市场或创作台。市场目录先显示真实上架作品；未上架时显示诚实空状态。详情把实际可加载3D与作者、许可、冻结版本和试装动作放在同一任务面。创作台左侧场景、右侧可滚动精确工具；390px时先场景、后工具，不横向溢出。私有工作台始终说明草稿与正式应用的边界。

## Signature interaction

选择或拖动真实陈设，数值输入与指针拖动经过相同安全体积验证；撤销重做恢复场景。老板在只读预览比较当前正式版本与待审稿，批准后打开的公司页面读取新快照并替换视觉Root，角色留在原地。模型加载失败保留旧Root，显示可恢复错误。

## QUALITY BAR

- 真实WebGL、真实JSON/GLB、真实私有保存/审批；不能把场景动画当业务成功。
- 公开市场只显示已上架版本；总部资格、老板应用、设计授权与AI能力各自检查。
- 不编造精选、热门、浏览量、下载量或官方认证；没有真实数据时明确空状态。
- 390px可操作，键盘表单/焦点/原生dialog，loading/error/empty/pending/disabled，关闭销毁预览资源。
- 场景不覆盖员工/任务/碰撞/楼梯/门禁，默认保留木质总部；未来主题须有实际几何差异。
- 用户正式确认前不得迁移生产、授予正式HQ资格、推GitHub或切换5312。
- 当前只约束安全陈设与主题变量，不以此声称任意建筑装修或高级美术重做已完成。
